# Lovable frontend instructions

Build a polished frontend for **Mini Kanban**, a deliberately small task board for one person and one project. Focus on making the complete core workflow reliable and pleasant to use.

Use one board with three fixed columns: **To Do**, **In Progress**, and **Done**. Every card represents committed work.

Users should be able to:

- Create and edit tasks with a required title, optional description, Low/Medium/High priority, and optional due date.
- Move and reorder cards using drag-and-drop.
- Move cards between columns with visible left/right controls as an alternative to dragging.
- Delete tasks after confirmation. Done tasks remain visible and can be moved back.

Save tasks, card order, column placement, and UI preferences in browser `localStorage`. Start with an empty board and use React with TypeScript.

Create a contemporary, desktop-first interface that remains usable on narrow screens. A restrained retro-futuristic or pixel-game influence is welcome, with task content kept clear and easy to read. Include a simple top-level selector for three distinct visual themes. Choose the palettes, theme names, default theme, typography, layout, interactions, and visual details yourself.

Use your product-design judgement to fill small gaps while keeping version 1 centred on this single-board task flow.
